## 🚀 Featured Project

### 🎫 Flåm Tourist Card 2026 — *solo full-stack product*

A tourist card platform for Flåm: visitors buy a pass, book experiences with local businesses, and carry the pass in Apple Wallet. Designed and built **alone over 374 commits between March and July 2026** (built with Claude Code), through feature branches, pull requests, and written architecture decision records.

- 🧩 **Turborepo + pnpm monorepo** spanning five apps: consumer web, consumer mobile, partner web, partner mobile, and an internal desktop dashboard
- ⚛️ **Web** in Next.js 15 & React 19 — TypeScript, Tailwind, Zustand, i18next
- 🐍 **FastAPI backend** with 8 data models, JWT auth, and 45 hand-written SQL migrations on Supabase Postgres
- 💳 **Stripe** PaymentIntents, webhooks & marketplace transfers paying out partner businesses
- 🍏 Signed **Apple Wallet** passes with HMAC-verified QR codes
- 📱 Mobile app in **React Native + Expo**; analytics & bookings dashboard in **Electron**

> The domain knowledge behind this project comes from my work as a tourist guide on the Flåm Railway — it solves a problem I observed daily on the job.
